# 小商城学习项目

这是一个基于 Vue 3 + Vite + Element Plus 的小型商城学习项目，包含：

- 商品列表与详情
- 购物车功能
- 论坛帖子列表与详情
- 简单的全局状态管理

适合 Spring Boot 课程前端对接和学习使用。

## 技术栈

- Vue 3
- Vite
- Vue Router
- Pinia
- Element Plus

## 运行方式

```bash
npm install
npm run dev
```

访问：

```bash
http://localhost:5173
```

## 目录说明

- `src/views`：页面视图
- `src/store`：状态管理
- `src/data`：mock 数据
- `src/router`：路由配置

## 课程目标

通过这个项目，学习：

1. Vue 3 组件开发
2. 路由与页面切换
3. 购物车状态管理
4. 前后端接口设计思路
5. 商城与论坛业务拆分
